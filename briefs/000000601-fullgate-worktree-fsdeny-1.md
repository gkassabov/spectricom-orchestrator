## PART A · a run that could not load its files is not a measurement
- **G-A1 — a unit-only load signal, `vite-fs-deny`.** It matches ONLY vitest's `Denied ID` load error, anchored — `^\s*(?:Error: )?Denied ID (\S+)` (ANSI stripped first, as today) — AND only when the denied path (query string stripped) lies under the realpath of a `node_modules` link that `_link_unit_deps` created for this run (i.e. outside the worktree root). `Failed to resolve import` / `Failed to load url` are NOT signals: a branch that imports a missing module is a product defect on the unit and build gates (at most an informational note). It is NOT added to the shared `ENV_BLOCK_SIGNALS` table that build (`:1714, :5395, :7045`) and SIT (`:5332, :5971`) classification read; it is evaluated by a unit-leg helper (e.g. `_unit_load_denied(raw, linked_realpaths)`) called only at the unit classification points named in G-A2. Never an assertion line.
- **G-A2 — never cached, never a baseline; a real failure still wins the verdict.** On a unit run whose output matches G-A1, the regression rule still runs over the LOADABLE files: if it confirms a regression among them the verdict is FAIL(product) and the detail also prints `also vite-fs-deny: N file(s) could not load (first: …)`; otherwise the verdict is BLOCKED(environment) with the count of unloadable files and the first one. Either way the run is not written to the unit-baseline cache (`_unit_is_cacheable` → False) and is not used as a full gate's `previous` measurement. Wiring points (name each with file:line in the handback): `_full_gate_unit` before `:6061` (it never calls `_classify_gate_failure` today), `_unit_is_cacheable` `:3688`, `_full_gate_previous` `:6138-6147` (store `failing_files: None` for such a run), and the baseline result in the unit gate (`:5436`, `:5572`).
- **G-A3 — the full gate's collection check, against a fixed reference.** After its unit leg, the full gate compares `tests_total` with a reference = the MAX `tests_total` of the last `full_gate_collection_ref_n` (repos.yaml, default 5) judged measurements on the chain (same content key first, else the nearest measured ancestors; the cache the reuse path already reads, `:5996-6060`), after subtracting the tests in `*.test.*` files deleted between the two SHAs (`git diff --name-status <ref-sha> <sha>`).
